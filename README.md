# GLIFFY.X

A clean, animated React + Vite digital agency website.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/pages` — main pages
- `src/components` — reusable components only
- `src/data/siteData.ts` — editable site content
- `src/index.css` — global design system and responsive styles

The project intentionally avoids excessive component splitting so the code stays readable and easy to maintain.
